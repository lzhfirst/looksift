# Looksift 2.0

[English](README.md) · **简体中文**

**找到喜欢的画风，带上自己的想法，得到为这个画面写的提示词。**

Looksift 是一套为 Qwen Image 2.1 编写绘图提示词的 Skill。你可以先在 [Looksift 官网](https://looksift.com) 浏览风格，选择一个风格编号或一张参考图，再说出自己想画的内容。Agent 会把选定的视觉表现方式与你的新主题、构图和要求结合起来。

最终得到的是一份可以带到绘图工具中使用的完整提示词。Looksift 负责准备提示词，图片由你选择的绘图工具生成。

## Looksift 解决什么问题

找到一张喜欢的图片，往往比解释它为什么好看容易。“水彩”“电影感”这样的词还不够具体：边缘如何处理、细节集中在哪里、材质如何受光、色彩怎样组织，都可能影响最终画面。

直接复制案例提示词，也容易把原图的人物、场景和构图一起带走。想画风景，却继承了肖像的布局；换了产品，画面里却留下参考案例才有的物件。

Looksift 帮助 Agent 理解可迁移的视觉方法，再围绕你真正想画的内容组织提示词。

| 常见困难 | Looksift 如何帮助 |
| --- | --- |
| “我知道喜欢什么感觉，但说不清。” | 从笔触、肌理、形体、边缘、光线和色彩关系等具体方面理解风格。 |
| 复制提示词后，原案例的主体总是跟着出现。 | 区分可复用的视觉表现与原案例的场景内容。 |
| 只说了一个主题，剩下的全靠猜。 | 追问影响画面的有效信息，或确认是否由 Agent 完善次要细节。 |
| 已经回答过的选择，还要重复确认。 | 复用当前请求中已确定的内容及适用的明确偏好。 |
| 翻译后画面内容变了，画内文字也被改掉。 | 保持各语言版本的场景一致，并保留要求显示的原文。 |
| 有参考图，却不知道怎么把画风写成文字。 | 用参考图路线说明图片的作用，同时清楚描述新画面。 |

## 2.0 提供哪些功能

- **两种明确的使用方式。** 按准确风格编号直接文生图，或为出图时提供的风格参考图准备提示词。
- **随包附带 4,012 条风格记录。** 编号记录包含可复用风格描述、完整场景案例与来源信息；安装后读取本地记录无需重新抓取来源网页。
- **围绕场景组织提示词。** 将主体、动作、空间关系、光线和取景连接成合理的画面。
- **有缺失才追问。** 判断所有主题是否缺少有效绘图信息，适用于风景、产品、海报、人物、动物等内容。
- **由你决定创作补充的范围。** 你可以自己补细节、交给 Agent 完善次要细节，也可以要求严格限于已给内容。
- **根据画幅重新组织构图。** 改比例时相应调整画面安排，而不是只修改末尾的数字。
- **按语言需求交付。** 日常交流使用你选择的语言；提示词可以提供英文与所选语言的完整版本，也尊重明确的单语言要求。
- **本地偏好管理。** 可以记住明确要求的默认值；重复选择只作为候选习惯，不会自动成为长期默认。
- **保留官方模板资源。** 附带指定版本的 Qwen Image 2.1 文生图及编辑提示词模板，以及来源版本和上游许可证。
- **按需输出结构化内容。** 明确要求 JSON 时，按所选官方模板的字段交付，便于接入单独的工作流。

### 一个风格编号代表什么

编号指向一条准确记录。可复用的风格描述解释视觉方法；完整案例展示这些方法怎样出现在某个具体场景中。案例中的主体，不是你下一张图必须保留的元素。

例如，1813 号的戏剧性光线和绘画肌理可以用于新场景，不必带入原例中的女子、裙装和城市窗户。新主题和环境由你的需求决定。你明确要求保留原配色时就保留；否则，Agent 会在你允许的创作范围内，把色彩关系调整到新主题上。

编号是标识，不是排名，也不是列表中的位置。记录被移除时可以保留空号。请使用当前安装版本中存在的编号；遇到不可用编号时，应当澄清，而不是悄悄换成相邻条目。

## 快速开始

### 1. 安装完整 Skill

使用支持 `SKILL.md` 技能、能够读取随包文件并运行本地 Python 的 Agent 宿主。附带的小工具需要 Python 3.9 或更新版本，只使用标准库。

下载并解压 [Looksift 2.0 安装 ZIP](https://github.com/lzhfirst/looksift/releases/download/v2.0.0/looksift-2.0.zip)，按宿主支持的技能安装方式安装其中的**完整 `looksift` 文件夹**。如果宿主支持从 GitHub 安装，使用[本仓库](https://github.com/lzhfirst/looksift)及其根目录 Skill。根目录保留 `SKILL.md`，内部目录结构保持完整。只复制入口文档，会缺少运行所需的风格记录和模板。

安装或更新后，在宿主中重新加载技能。Skill 包不包含模型权重和出图服务，绘图环境需要另外选择。

### 2. 选择风格的提供方式

| | A：直接文生图 | B：使用风格参考图生成 |
| --- | --- | --- |
| 风格来源 | 一个准确的 Looksift 风格编号。 | 出图时交给绘图工具的参考图片。 |
| 交给 Agent 的内容 | A 方式、风格编号、新主题和已知要求。 | B 方式、新主题和已知要求；编号可选。 |
| 写提示词时是否必须上传参考图 | 不需要。 | 普通风格参考提示词准备不需要。 |
| 出图时交给绘图工具的内容 | 完整提示词。 | 完整提示词和所选参考图。 |
| 使用的模板依据 | Qwen Image 2.1 文生图模板。 | Qwen Image 2.1 编辑模板。 |

如果你只说了主题，Looksift 会先询问方式。单独给出编号或附件，不会被默认为已经选择了某条路线。

### 3. 说出这次想画什么

你可以先提出一个想法，在交流中逐步补足。如果关键选择已经想清楚，也可以一次说完。

**A 方式请求示例：**

> 使用 Looksift，选 A，风格编号 0048。画一只赤狐卧在一小丛蕨叶旁，方形画幅，完整露出身体，尾巴绕在前爪边，轮廓周围留足空白。背景用暖象牙色，光线柔和自然，不要文字。你可以补充次要细节，但保留主体和布局。用中文与我交流。

**B 方式请求示例：**

> 使用 Looksift，选 B。我会在出图时上传风格参考图。画一座黎明时分的孤独灯塔，立在低矮岩岛上，从平静海面望过去。灯塔放在右侧，左侧留出开阔水面，不要人物和文字。横向 16:9。次要细节由你完善，最终参考图只提供视觉风格。用中文与我交流。

这些是可以照着尝试的需求示例，并不表示这两个新主题已经出过图。上面的图片画廊有各自真实记录的场景提示词。

### 4. 补齐真正影响画面的缺口

Agent 会保留已经提供的信息，每次只问一个必要的未决事项。例如缺少风格编号、影响画面的关键细节、画幅比例，或尚未明确由谁完善细节。

不需要机械填写一张问卷。简短而准确的描述可能已经足够，堆了许多模糊形容词的长句也可能仍需澄清。判断依据是缺少的信息是否影响你真正想要的画面。

### 5. 把提示词带到绘图工具

复制完整提示词，在选定的 Qwen Image 2.1 工作流中使用，并设置已确认的画幅。B 方式还需要同时附上所选参考图。对话中提到某张图，不等于图片已经自动传给出图模型。

查看实际结果，再说明想调整的内容。如果改变画幅，Looksift 应当为新画幅重新组织描述，同时保留已确认的主体和要求。

## 最后会得到什么

普通交付是一份完整的画面描述，包含所需主体、有关的动作与关系、构图、视觉表现、材质、光线和环境。要求出现在画内的文字保持原样。

默认提供完整英文提示词，以及所选交流语言的完整对应版本。如果交流语言就是英文，一份完整英文即可兼任两者。你也可以明确要求只输出一种语言。提示词后有一条简短使用说明，交代已采用的比例；参考图路线还会提醒出图时附上图片。

**仓库顶部的语言切换只改变说明文档的语言，不会设置 Agent 的交流语言，也不会改变提示词输出偏好。**

需要供程序读取的结果时，可以明确要求 JSON。文生图包含 `rewritten_prompt` 和 `wh_ratio`；编辑方式增加 `ratio_follow`，两个比例字段只填其中一个。只要 JSON 时，会交付官方对象，不加入开场说明或额外翻译字段。具体格式和保留的原件见[模板指南](skills/looksift/references/qwen-image-2.1-official/README.md)。

## 偏好由你决定

你可以让 Agent 记住默认画幅、交流语言，或允许补充次要细节等明确偏好。当前请求中的明确要求优先于以前的默认值。

重复出现的个人选择可以成为候选习惯，但重复不等于同意永久采用。临时选择只作用于当前请求；Agent 自己做出的创作选择也不会变成你的习惯。

偏好数据保存在本机，位于可分发包之外，不随公开仓库发布。没有内置云同步或跨设备同步。共用机器需要为用户确定可靠的独立档案；替换 Skill 不会自动删除单独存放的偏好。详细行为与控制方式见[偏好指南](skills/looksift/references/user-preferences.md)。

## 常见问题

**Looksift 会直接生成图片吗？**  
它交付提示词。图片由另外的绘图工具生成，Skill 不会自动发起付费出图请求。

**每次都必须提供风格编号吗？**  
A 方式需要准确有效的编号；B 方式可以不提供编号，先准备参考图路线的提示词。

**必须先把参考图传给 Agent 吗？**  
普通 B 方式准备提示词时，可以等到出图时再把图交给绘图工具。如果要求 Agent 分析现有图片、编辑特定画布，或保留某些具体视觉内容，对话阶段可能需要那张图片。

**参考图的人物和背景会被带到新画面吗？**  
提示词会明确风格参考图只承担视觉表现，并另外描述新内容。最终执行仍受绘图模型和实际输入影响。

**提示词可以给别的模型使用吗？**  
可以自行尝试，但模板和目标模型是 Qwen Image 2.1。不同模型可能有不同理解，不承诺跨模型效果一致。

**这是不是 Qwen 官方的提示词增强模型？**  
Looksift 把官方模板资源提供给宿主 Agent 使用，本身不运行 Qwen 另外发布的提示词增强模型权重。

**能保证画风一模一样吗？**  
不能。提示词结构正确，不等于实际视觉结果完全一致；需要结合生成图片、参考图和实际设置来判断。

**英文首页会强制使用英文对话吗？**  
不会。文档语言、对话语言和提示词语言是不同的选择。
