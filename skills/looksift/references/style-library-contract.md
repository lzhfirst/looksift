# Looksift library responsibilities

The production controller's current full-manifest defines the complete ID set.
The bundled index preserves those exact four-digit IDs, current website names,
four bilingual prompt fields, original themes, ratio, source version and provider
submission provenance. Identity is never inferred from order or name. Image
completion, refusal or isolation does not remove a style. No legacy mapping fallback.

The gallery is the main product for discovery, comparison and choosing styles or
available reference images. The Skill writes new-theme prompts. It does not modify
production jobs, publish the site, automatically fetch images or generate them.
Prompt writing is independent of the production checkout and website connectivity.

For a supplied number, use the exact index record and read both reusable style
and full example fields. A requires a valid number and uses the full original T2I
template. B uses the full original Edit template with no required number/current
upload; optional sources follow explicit roles. A supplied number does not select
A; an attachment does not select B. Never invent an unavailable record or observed
image. Explicit method choice/delegation or an applicable explicit preference
settles mode; otherwise ask A/B alone.

The [workflow](../WORKFLOW.md) is the maintained interaction and delivery reference.
It covers one unresolved question at a time, direct input instead of fake fill
options, scope-aware detail handling for every subject, ratio before composition,
visual-method/color transfer, image roles and final output quality. Reuse resolved
facts and explicit applicable intent; do not force a fixed interview or infer
authorization from silence, text length, a mode choice or ratio-only delegation.

The [preference guide](user-preferences.md) governs runtime memory. The host Agent
understands intent and merges current context with applicable actual memory. The
helper stores only approved fact fields, distinguishing explicit defaults from
candidate habits; temporary/Agent-selected values do not silently become defaults.
Keep data outside the bundle and source library, isolate users/tests and confirm
real writes/deletes before claiming success. Do not create cross-account sync.

Core runtime instructions are English for maintenance. Ordinary communication,
including questions, labels, reminders and recovery, follows the user's selected
language and applicable communication style. Examples are localizable and adaptable;
neither Chinese source records nor English instruction files fix the reply language.
A conversation tone preference is not the picture's visual style or mood.

The fixed first-use/reload logo and root URL remain in root SKILL.md. Reload keeps
the brief; ordinary follow-ups/internal reads/maintenance do not repeat the opening.
Strict JSON/API-only output omits it. Higher-priority host disclosure rules remain
in force; concise examples cannot waive them.

Transfer brushwork, texture, form/edges, light/shade and color organization without
copying example content or automatically enforcing its palette. Concrete colors
fit the new theme or explicit user intent within creative scope. B without source
evidence uses relative inheritance; B prompt bodies explicitly state image roles.
Single-image prose is natural; multiple actual/agreed inputs use ordered role tags.

Ordinary delivery contains complete English and selected-language versions of one
scene (no duplicate if the selected language is English). Preserve exact visible
text. Explicit language/single-language/JSON requests take priority. A short localized
tail states ratio/follow target and B's generation-time reference upload. No ordinary
machine-parameter block; no forced image upload for A or preliminary upload for B.
Use the gallery link when helpful without inventing UI controls/deployment claims.

Explicit JSON retains original schemas: T2I has rewritten_prompt/wh_ratio; Edit
adds ratio_follow, with exactly one ratio field nonempty. Do not add translation
fields. Template originals, pinned manifests and upstream licenses remain intact.
Text/template validation alone is not evidence of generated-image fidelity.
